# Figure data assembly and plotting

Run commands from the repository root after installing requirements.txt. Python 3.10+ and MATLAB with Statistics and Machine Learning Toolbox are required. Inputs are NPZ files containing named numeric or Unicode arrays; object/pickle arrays are not accepted. N = individuals, G = groups, R = regions, K = gradients, M = fitted models, B = draws. All participant and region rows must be aligned upstream; complete finite values are required.

```sh
python workflows/run_figure_demo.py --output outputs/figure_demo
python workflows/assemble.py --figure ExtendedDataFigure6 --input inputs/rsa.npz --output outputs/source --repetitions 10000
```

In MATLAB:
```matlab
addpath('figures');
render_panels('outputs/figure_demo/Figure2/panels.mat','outputs/figures');
```

Each figure gets source_data.npz, source_data.mat, panels.mat and a panel field inventory. The demo runs all 24 figure groups with generated data and 24 draws. Demo spin-index arrays are only interface fixtures, not spatial nulls for empirical inference. Replacing the inputs does not remove the need to run the relevant upstream model. The assembly routes cover the listed analysis components; they do not reproduce every manuscript panel layout automatically.

Additional figure-specific assembly, model bridges and full-layout rendering are documented in [SPECIALIZED_INPUTS.md](SPECIALIZED_INPUTS.md). Run `python workflows/run_remaining_demo.py` for all 22 specialized routes.

## Webb final statistics

```sh
python workflows/run_webb.py --mode cluster --input inputs/china_webb.npz --output outputs/china_webb --repetitions 10000 --seed 42
python workflows/run_webb.py --mode international --input inputs/nations_webb.npz --output outputs/nations_webb --repetitions 10000 --seed 2026102201
```

China inputs: point [R], influence [G,R], gradients [R,K]; optional weights [B,G] reproduce an existing random-weight realization. MATLAB china/prepare_webb_influence.m creates point and influence from an aligned table and cortex matrix using the common 28-covariate, province/city random-intercept model. Its dense covariance requires memory proportional to N squared. The public calculation freezes that fitted covariance for HC2 cluster-score perturbations. Balanced antithetic Webb draws then give standardized spatial correlations, simultaneous standardized gradient coefficients, their percentile intervals, standard errors and sign-tail p values. MATLAB prctile convention is implemented with NumPy hazen quantiles. Component orientation must be fixed before resampling.

International inputs: X [N,P] full-rank nuisance design including intercept, Y [N,R] standardized harmonized cortical data, g [N] contiguous zero-based country/state IDs, C [G] one cultural predictor, pool [Q,G] permutation index pool, targets [R,K] spatial references. Use the design and ComBat functions in international/run_example.py. Each Webb draw reconstructs endpoint artifacts and refits protected REML. Inner artifact screening remains |r| < .01. Percentiles use NumPy linear quantiles. Country and USA inputs are processed separately. The international mode returns map_draws [B,R]; add a model dimension before passing draws to the figure assembler.

## Additional panel types

For extra China predictors such as PC3, `china/generate_figure_models.m` accepts a MAT file with `T`, `cortex` [N,R] and `predictor_names`. `T` follows the full schema in the root README and `prepare_china_table.m`; additional predictor columns must be numeric. The function fits one model per predictor/ROI using the common 28 covariates and province/city intercepts and saves coefficients, model-based intervals and p values. These model intervals are distinct from spatial Webb intervals.

`figures/plot_geography.m` accepts a MAT file containing `boundaries` (cell array of projected polygon coordinate matrices), `xy` [N,2], `values` [N] and `marker_sizes` [N] or scalar. Boundaries and points must share the same projected CRS. The output stem produces `.fig` and `.png`; supply appropriately licensed boundaries.

figures/render_panels.m also accepts custom MATLAB cell arrays named panels. Each struct has folder, name and kind plus numeric fields listed in figures/panel_catalog.json. Custom surface panels require vertices [V,3], one-based triangular faces [F,3], values [V], view [azimuth,elevation], and clim [min,max]. The atlas mesh is bundled under assets/surfaces; see figures/README.md. Table panels use matrix, labels and columns. Interval panels use estimate, low, high, labels and xlabel. Surface preprocessing remains external. Reference geometry and geographic projections are bundled; alternative atlases require matching geometry. All exported statistical plots use the shared publication_style function and save editable MATLAB .fig files.
