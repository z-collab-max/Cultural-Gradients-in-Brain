# Analysis examples

Bundled individual-level examples are synthetic. Study-input adapters process data supplied by the caller. The saved simulation reference files contain simulated observations and effects. These examples do not reproduce the empirical numerical results in the manuscript.

## 1. Set up the extracted folder

- MATLAB R2022b or later, Statistics and Machine Learning Toolbox. The simulations also use Parallel Computing Toolbox.
- Python 3.10 or later (`python -m pip install -r requirements.txt`).
- The province shapefile plotter additionally requires MATLAB Mapping Toolbox.

Open the extracted folder containing this README, `requirements.txt`, `china/` and `international/`. This is the repository root. Use it as both your terminal working directory and MATLAB's **Current Folder**. Run `python ...` commands in the terminal and MATLAB blocks in the MATLAB Command Window; keep both working directories at the repository root.

In the terminal, install the Python dependencies:

```sh
python -m pip install -r requirements.txt
```

Sections 2–5 use generated synthetic inputs or bundled simulation references: no personal input files are needed. Run China first, then international analyses, simulations and figure workflows. These sections are independent; within each section, follow the command blocks in order. The small repetition counts demonstrate execution; increase them explicitly for inference.

Default outputs are created under `outputs/` in the repository. Explicit relative input/output arguments resolve from the working directory unless an input schema specifies JSON-relative paths. Rerunning a command may overwrite its previous outputs; use a different output directory to retain another run. Do not move only an individual script: retain the complete folder tree, including `assets/` and `simulation/reference/`.

Some Python China adapters call MATLAB. For those adapters, put `matlab` on your terminal's PATH or set `MATLAB_EXECUTABLE` to your installed MATLAB executable, as described in [China input requirements](workflows/study_inputs/CHINA_INPUTS.md).

## 2. Run the China example in MATLAB

The [shared China chain](china/SHARED_CHAIN.md) starts from keyed raw cortical measurements and covariates and runs ComBat, center-artifact removal, mixed models and unrestricted province shuffles. Its outputs feed the Figure 2 gradient and Figure 3 commonality panels.

```matlab
addpath('china');
run_china_example;                         % 3 synthetic ROIs, seven tasks
```

The command computes point estimates. An optional longer run, `run_china_example(fullfile(pwd,'outputs','china_bootstrap'),200,3)`, also estimates indirect-effect uncertainty using 200 province bootstrap samples. Set the repetition count explicitly for a larger run. The random seed is fixed and saved results include the repetition count.

`china_covariates.m` defines the 28 primary covariates: age, sex, education, genetic PCs 1–10, paternal and maternal education, intracranial volume, total surface area, absolute latitude, terrain ruggedness, historical humidity, temperature, sunshine and precipitation, population density, green space, per-capita natural-disaster frequency, and HDI education and income. Each model includes both random intercepts:

```text
response ~ predictors + 28 covariates + (1|province_birth) + (1|province_city)
```

`province_city` is the combination of birthplace province and birthplace city. Additional adjustment columns can be passed in the `additional` argument of the fitting functions. See [input schema](china/INPUT_SCHEMA.md).

`run_china_example` saves the fitted results, calls `export_china_source` to create source-data tables and RDM arrays, and calls `plot_china_example` to produce `.fig` files. The export and plotting steps can also be run independently on an existing output folder.

`fit_china_mixed.m` estimates cortical associations. `fit_china_relocation.m` estimates birthplace culture, relocation status, their interaction, and destination-minus-birthplace culture; it also returns separate stayer and relocator maps. `fit_china_mediation.m` fits a, b, c and c-prime paths with mixed models and returns their coefficients and the indirect effect a×b. Province bootstrap samples use common observations across paths and relabel repeated clusters.

Behavioral PCA retains the first components exceeding 85% cumulative variance. Input metric directions are supplied to `behavior_pcs.m`. Coefficients are averaged across retained behavioral PCs within a task. `best_task_order.m` searches all 5,040 task orders, maximizes the mean absolute ROI Spearman RSA coefficient, and saves one selected order, its RDM, RSA map and slope map. Ties use the first lexicographic order. Point-estimate runs use indirect effects; bootstrap runs use indirect effects divided by their bootstrap SE before averaging within each task.

For a direct province-level permutation example:

```matlab
[T,cortex]=make_synthetic_china;
statistic=@(Q)china_mixed_statistic(Q,cortex);
permutation=permutation_china(T,statistic,20,20261103);
output_dir=fullfile(pwd,'outputs','china');
if ~isfolder(output_dir),mkdir(output_dir);end
save(fullfile(output_dir,'permutation.mat'),'permutation');
```

Use 20 permutations for a quick run and 10,000 for a longer run. The callback defines the complete statistic evaluated for each shuffled culture table. Culture PC rows are shuffled jointly across provinces; the same province mapping is used for birthplace and destination culture. All other table fields remain fixed. The callback can also include preprocessing and mediation or relocation fits.

## 3. Run the international example: Python, then MATLAB

The [Figure 5 workflow](international/FIGURE5.md) connects raw individual cortex and named unit-level macro variables to within-unit ComBat, endpoint models, the two spatial comparisons, geographic source data and editable statistical panels.

```text
python international/run_example.py --permutations 20
```

For a longer run, use `--permutations 10000`. The example generates 26 synthetic countries and 18 synthetic US states, harmonizes scanner batches within each unit with ComBat, builds the country/state-specific covariate design, generates artifact PCs, removes artifacts with GLS-score protection and fits country/state random-intercept REML models. Nations models contain 29 nuisance-design columns, including the intercept; the USA model contains 21. Exact covariate labels and macro-variable blocks are defined in `international/core/model_spec.py` and saved in the results. Nations macro PCA retains all components within each block.

The endpoint retains 25 artifact PCs for Nations and 17 for USA. Artifact construction retains its internal |r| < 0.01 rule. Outer tests directly shuffle unit-level cultural scores, without correlation screening or an additional observed-culture nuisance term. Permutation and spin probabilities use `mean(abs(null) >= abs(observed))` without a +1 correction.

```matlab
addpath('international'); plot_example;
```

Results include synthetic input matrices, harmonized matrices, fitted maps, permutation indices and null maps, source-data CSV files and editable `.fig` files.

## 4. Run and plot new simulations: MATLAB, Python, then MATLAB

```matlab
addpath('simulation');
run_all_simulations(true);    % 2 realizations per artifact bin
```

After this MATLAB call finishes, export the newly generated SI3 results in the terminal:

```sh
python simulation/export_si3_source.py --source outputs/simulation/si3_smoke --output outputs/simulation_source/si3_smoke
```

Then return to MATLAB to draw the new results:

```matlab
addpath('simulation');
plot_ed2(fullfile(pwd,'outputs','simulation','ed2_smoke','sim_data_unified_v3_beta2x_matched_range6p0_smoke.mat'));
plot_si3(fullfile(pwd,'outputs','simulation_source','si3_smoke'));
```

To draw the bundled complete reference results without generating new simulations, use `plot_ed2; plot_si3;` with no arguments. These commands save to the same figure directories and replace previously rendered simulation figures.

For an optional full run with 100 realizations per bin, use `run_all_simulations(false)`.

`generate_ed2.m` implements the paired sampling-structure simulation. `generate_si3.m` implements one, three and five artifact sources. Setup uses Twister; individual realizations use Threefry with explicit seeds in both serial and parallel execution. Full simulation settings are in the scripts. The simulation PC settings remain part of their experimental designs.

To derive plotting arrays from a new full SI Fig. 3 run:

```text
python simulation/export_si3_source.py --source outputs/simulation/si3 --output outputs/simulation_source/si3
```

```matlab
plot_si3(fullfile(pwd,'outputs','simulation_source','si3'));
plot_ed2(fullfile(pwd,'outputs','simulation','ed2','sim_data_unified_v3_beta2x_matched_range6p0.mat'));
```

All plotters use `simulation/publication_style.m` and save editable MATLAB figures.

## 5. Assemble the figure examples in Python, then render in MATLAB

These assembly demos generate their own synthetic arrays; they do not consume the China or international outputs above. In the terminal, run:

```sh
python workflows/run_figure_demo.py
python workflows/run_remaining_demo.py --output outputs/specialized
python figures/run_layout_demo.py
```

See [workflows/README.md](workflows/README.md) for the 24 figure-group input contracts, dedicated assembly routines, Webb final statistics and MATLAB panel rendering. Run `python workflows/run_figure_demo.py` to exercise all assembly routes with synthetic inputs.

Reference surface meshes, geographic boundaries, nine dedicated layouts and their synthetic examples are documented in [figures/README.md](figures/README.md). Run `python figures/run_layout_demo.py` to generate their example inputs and geographic panels.

The [specialized workflows](workflows/SPECIALIZED_INPUTS.md) add 22 source-data routes, named model branches and result-file bridges. Run `python workflows/run_remaining_demo.py --output outputs/specialized`, then call MATLAB `render_workflow` for each generated figure directory.

After running both figure assembly demos, render their source data with:

```matlab
addpath('figures');
files=dir(fullfile('outputs','figure_demo','**','panels.mat'));
for k=1:numel(files)
    render_panels(fullfile(files(k).folder,files(k).name),fullfile(files(k).folder,'rendered'));
end
root=fullfile(pwd,'outputs','specialized');
folders=jsondecode(fileread(fullfile(root,'run_index.json')));
for k=1:numel(folders)
    source=fullfile(root,folders{k});
    render_workflow(source,fullfile(source,'rendered'));
end
```

These demos verify assembly and plotting with synthetic inputs. Raw-input model runs use the separate China and international commands above. Empirical input tables, task data and aligned spatial references must be supplied according to the linked schemas; cortical reconstruction and vertex smoothing are external preprocessing steps.

## 6. Supply your own inputs

Create an `inputs/` directory locally, or keep inputs outside the repository and pass their paths explicitly. No empirical participant files are distributed. Root `inputs/`, `local/` and generated `outputs/` are excluded by `.gitignore`; retain individual-level inputs and intermediates in your local analysis environment.

| Analysis | Suggested input location | Input schema and ordered commands |
|---|---|---|
| China shared preprocessing and models | `inputs/china/`: `participants.csv`, `covariates.csv`, `cortex.mat`, `culture.csv` | [Shared China chain](china/SHARED_CHAIN.md). With your own inputs, skip `make_china_chain_inputs`; run preprocessing/model fitting, then the required assembler, then its plotter. |
| China mediation and relocation tables | An aligned MATLAB table and cortical/task matrices | [China model schema](china/INPUT_SCHEMA.md) and [study-input workflows](workflows/study_inputs/README.md) |
| International / USA | `inputs/international/`: cohort participant/cortex/unit tables, pools, targets and spins | [Figure 5 input schema and pipeline](international/FIGURE5.md). Run input preparation, `fig5_chain.py`, then `render_fig5`. |
| Other figure-specific analyses | Explicit file paths under `inputs/` or an external data folder | [Figure-to-code map](analyses/FIGURE_COVERAGE.md), [study adapters](workflows/study_inputs/README.md), [specialized input contracts](workflows/SPECIALIZED_INPUTS.md) |

For every branch the order is **input preparation → calculation → source-data export/assembly → plotting**. Some model runners perform export automatically; the linked workflow gives the separate commands where needed. Statistical plots require the saved arrays and metadata, not just a screenshot or a CSV of p values. Match participant keys, ROI order, cultural-unit order and valid spatial rotations to the selected schema. ED4 cortical reconstruction and smoothing are external preprocessing steps.
